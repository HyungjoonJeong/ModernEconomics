# 현대경제강독 퀴즈

7개 강의의 단답형 예상문제 738개를 담은 PC·모바일용 반응형 웹 앱입니다. 외부 라이브러리, API 키, 로그인, 유료 서버가 필요하지 않습니다.

## 바로 실행

압축을 푼 뒤 `index.html`을 브라우저로 열면 바로 사용할 수 있습니다. 모든 문제·스타일·앱 코드는 이 HTML 안에 포함되어 있습니다. 휴대폰에서는 아래 GitHub Pages 방식으로 배포한 주소에 접속하는 것이 편리합니다.

## GitHub Pages에 배포하기

1. GitHub에서 새 저장소를 만듭니다. 예: `econ-quiz`. 무료 개인 계정에서는 Public 저장소로 생성합니다.
2. **Add file → Upload files**를 열고 압축을 푼 폴더 안의 파일들을 올립니다. ZIP 파일 자체를 올리는 것이 아닙니다. 저장소 첫 화면에 `index.html`이 바로 보이도록 올려 주세요.
3. **Commit changes**로 저장합니다.
4. 저장소의 **Settings → Pages**로 이동합니다.
5. **Source: Deploy from a branch**, **Branch: main**, **Folder: /(root)**를 선택하고 **Save**를 누릅니다. 기본 브랜치 이름이 다른 경우 그 브랜치를 선택하세요.
6. 배포가 완료되면 Pages 화면에 표시되는 주소로 접속합니다. 일반적인 형태는 `https://사용자이름.github.io/econ-quiz/`입니다. 이 주소를 PC와 휴대폰에서 사용할 수 있습니다.

GitHub 공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

이 배포 방식에서는 문제 자료가 웹에 공개됩니다. 파일에는 서버나 로그인 기능이 없으며, 학습 기록은 방문자의 브라우저에만 저장됩니다.

## 휴대폰·PC에 앱처럼 설치

- **Android Chrome / PC Chrome·Edge:** 배포 주소에 접속한 뒤 주소창의 설치 버튼 또는 브라우저 메뉴의 앱 설치를 사용합니다. 설치가 가능한 경우 앱의 ‘기록 관리 · 앱 설치’에도 버튼이 나타납니다.
- **iPhone / iPad Safari:** 배포 주소에서 **공유 → 홈 화면에 추가**를 선택합니다.
- 처음 온라인으로 접속해 파일이 캐시된 뒤에는 오프라인에서도 복습할 수 있습니다. 운영체제나 브라우저가 캐시를 삭제하면 다시 온라인으로 접속해야 합니다.
- 로컬 HTML을 직접 여는 `file://` 방식은 설치·서비스 워커 기능을 지원하지 않습니다. 일반 퀴즈 기능은 사용할 수 있습니다.

## 학습 기능

- 강의별 학습, 여러 강의 선택, 전체·미학습·오답·북마크 범위
- 10·20·50문제 또는 선택 범위 전체, 순서 섞기
- 답변 입력 또는 머릿속으로 답하기 → 자료의 정답 확인 → 직접 채점
- 학습 도중 나갔다가 이어 풀기, 입력 답변과 공개 상태 저장
- 마지막 채점이 오답인 문제만 모으는 오답 노트
- 북마크, 문제·정답 검색, 강의 필터, 20개씩 페이지 이동
- 회차 결과와 입력 답변 확인, 틀림·건너뜀 재학습
- JSON 백업·불러오기, 기록 초기화 확인창
- 키보드: `Ctrl/⌘ + Enter` 정답 확인, 정답 공개 후 입력창 밖에서 `1` 오답 / `2` 정답

### 채점과 통계 기준

서술형 답변·여러 핵심어가 있는 문항도 있어 자동 정오 판정은 하지 않습니다. 원문 정답과 대조한 뒤 본인이 채점합니다. 누적 정답률은 정답 채점 횟수 / 전체 채점 횟수입니다. 건너뛰기는 채점 횟수, 오답 노트, 미학습 여부에 영향을 주지 않습니다. 이전에 틀린 문제를 다시 맞혔다고 채점하면 오답 노트에서 빠집니다.

### PC·모바일 간 기록 이동

자동 동기화는 없습니다. 왼쪽 하단 ‘기록 관리 · 앱 설치’에서 백업 JSON 파일을 내려받고 다른 기기에서 불러오세요. 모바일에서도 같은 메뉴는 대시보드 아래의 ‘기록 관리 · 앱 설치’ 버튼으로 열 수 있습니다. 불러오기는 기존 기록을 합치는 것이 아니라 교체합니다.

시크릿 모드, 브라우저 데이터 삭제, 저장소 권한 제한 시 기록이 보존되지 않을 수 있습니다. 같은 브라우저라도 로컬 파일과 배포 주소는 서로 다른 기록을 사용합니다.

## 파일과 수정 방법

| 파일 | 용도 |
|---|---|
| `index.html` | 바로 실행·배포하는 완성본. 문제/스타일/코드가 모두 포함됨 |
| `manifest.webmanifest`, `sw.js`, `icon*` | 앱 설치·오프라인 지원 |
| `data.js` | 738문항 원본 데이터 |
| `app.js`, `style.css`, `index.template.html` | 수정용 소스 |
| `build.mjs` | 소스를 단일 HTML로 합치는 빌드 스크립트 |
| `.nojekyll` | GitHub Pages의 정적 파일 처리용 |

배포만 하실 때는 Node.js가 필요하지 않습니다. 소스를 수정할 때만 Node.js로 `node build.mjs`를 실행해 `index.html`을 다시 생성해 주세요. 외부 npm 패키지는 필요하지 않습니다. 오프라인 파일을 업데이트할 때는 `sw.js`의 `CACHE` 버전도 올리고, 기존 앱 탭을 모두 닫은 뒤 다시 접속하세요.

## 검증 범위

전체 738문항, 강의별 문항 수·번호 연속성·문제와 정답 누락 여부 및 JavaScript 구문을 검사했습니다. 모의 DOM 환경에서 학습·채점·복습·저장·재개·백업 데이터 유효성 흐름을 확인했습니다. 실제 브라우저 미리보기 도구 연결 오류로 화면 렌더링과 실제 기기 설치·오프라인 실행은 직접 확인하지 못했습니다. GitHub 업로드·실제 배포는 이 파일 묶음에 포함되지 않습니다.
